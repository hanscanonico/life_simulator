# Design studies

Dated research notes written before a sweep was pre-registered, kept here because the record
cites them by summary. They are not the design of record: `docs/DESIGN.md` and
`docs/design_record.md` are. Each study is kept as written, but for its scratchpad paths, which
now say what was not kept or where a tool went.

**Every number in them is pilot** — measured on a throwaway copy of the engine or on stored
pilot worlds — unless the record says otherwise. A pilot number is not a finding.
